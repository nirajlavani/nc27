# Iterations

One directory per invitation concept. The side panel lists a directory only when it matches the completeness rule in the plan.

Do not put moodboard images or shared assets here. Add a concept by creating a new directory. Leave existing directories in place.

The descriptor fields are in `invites/plans/2026-10-27-1502-feat-invite-studio-plan.md`.

To add one, follow `invites/notes/adding-designs.md`: a folder named after the `id`, a `descriptor.json`, and the card images beside it.
