# Invites

Local studio for NC27 invitation ideas. A kankotri and an invite are the same paper suite.

This folder holds the notes, the plan, the moodboard, shared art, and later the app and the saved iterations. A later session can start here without the chat that created it.

- `notes/adding-designs.md` — **start here to add an invitation or card art**: the folder, the descriptor, image sizes, and what needs code
- `notes/orientation.md` — what the folders mean, and how to add an iteration
- `plans/2026-10-27-1502-feat-invite-studio-plan.md` — the contract for the descriptor, the page, and the build
- `assets/` — shared art, not an invitation
- `moodboard/` — inspiration images, not an invitation
- `iterations/` — one directory per saved invitation

From this folder, `npm test` runs the catalog checks, `npm run dev` opens the studio, and `npx playwright test` runs the browser checks.

The page is for the review team. Delegates do not get a link from this project. Printing, mailing, guest lists, and RSVP are out of scope.
