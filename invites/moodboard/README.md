# Moodboard

Inspiration for NC27 invitations: reference photos, paper samples, color, and layout ideas.

Drop images here so a later session can see the visual direction. Nothing in this folder is an invitation, and the side panel does not list it.

Useful references when you have them:

- Closed suite, belly band, and the inner stack as separate pieces
- French-door or gate-fold openings
- Envelope flaps
- Booklet covers
- A letter card, a code card, and a theme card as three faces
