# Orientation

A kankotri and an invite are the same thing: one paper invitation suite for NC27.

## Folders

- `iterations/` — every saved concept. One directory per concept. The side panel lists the ones the plan calls complete.
- `assets/` — art shared across the project. Not a concept, and not a panel row.
- `moodboard/` — inspiration only. Not a concept, and not a panel row.
- `plans/` — the implementation plan. Field names, completeness, and the open / splay / turn / reset behavior live there.

## Adding a concept

The step-by-step guide, with descriptor fields and image sizes, is `notes/adding-designs.md`.

Add a new directory under `iterations/`. Do not rename or overwrite a directory that is already there. Replacing art means replacing one image file inside one concept's directory.

Opening, splaying, turning, reading, and reset do not write anything. The one thing the page writes is an upload from its dialog. That creates a new directory, or edits one outside the Default group, and never touches the four starters.

The descriptor file name, the fields, and which constructions the page can open are in `plans/2026-10-27-1502-feat-invite-studio-plan.md`. Follow that file rather than inventing a second schema.

## What the page is for

The review team uses it to compare ideas. It does not send invitations or give a delegate a personal link.
